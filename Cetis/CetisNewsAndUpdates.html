Version History
Release Timeline
Current Release

CETIS v2.1.6

The biggest change to the user interface since the introduction of CETIS. Implements the Office Ribbon UI, improved native filtering and exporting. Full support for Access 2010 through Microsoft 365 (x64 and x86).

Statistical Update

EPA TST Method Added

Implementation of the U.S. EPA Test for Significant Toxicity (TST) using Welch’s t Test — the bioequivalence approach that controls the false negative rate.

Comparison Methods

Robertson-Preisler & Zajdlik Tests

New implementation of the Robertson and Preisler ratio test and the Zajdlik two-sample Z test for comparing two different point estimates.

Quality Control

Two-Sided CUSUM Plot

A new two-sided CUSUM (Cumulative Sum) plot for sensitive detection of trends in reference toxicant data and other quality control applications.

Security

MD5 Data Integrity

New data security measures including the calculation and storage of MD5 hash digests to verify dataset integrity for audits and regulatory compliance.

Platform

64-bit Support

Full support for both x64 and x86 versions of Microsoft Access, ensuring compatibility across all modern workstation configurations.
