Features

Software Features

From automated decision trees to advanced regression models, CETIS provides everything you need for professional toxicity data analysis.

Core Feature
Decision-Tree Automation
Let CETIS make the statistical decisions for you — or take full manual control.

CETIS implements decision-making logic that makes most, if not all, decisions for you in terms of selecting the correct statistical method and verifying that all assumptions are met.

You can also override any software-made decision and manually select methods and options of your choice.

Since federal and state programs have different decision-making rules, CETIS provides a system to quickly change decision rules depending on which jurisdiction governs the testing — whether U.S. EPA, Environment Canada, or individual state requirements.

Automatic Method Selection

Intelligent algorithms select the appropriate statistical test based on data characteristics and regulatory requirements.

Assumption Verification

Every assumption is automatically checked: normality, homogeneity, outliers, and monotonic trends.

Manual Override

Full control when you need it. Override any decision and select your preferred methods and options.

Analysis
Statistical Analysis

Linear Regression (MLE)

Four models: Log-Cumulative Normal (Probit), Log-Logit, Log-Gompertz, and Log-Angle. Emulates U.S. EPA Probit and SAS Probit.

Non-Linear Regression

41 models including Logistic, Log-Logistic, Cumulative Normal, Gompertz, Weibull, Morgan-Mercer-Flodin, and hormesis-adjusted variants.

EPA TST Method

Welch's t Test for Significant Toxicity — the bioequivalence approach that controls the false negative rate.

Hypothesis Testing

NOEL/LOEL (NOEC/LOEC) calculations with automated follow-up point estimation for complete analysis.

Point Estimation

Spearman-Karber, Trimmed Spearman-Karber, and interpolation methods with 95% confidence intervals.

Residual Analysis

Pearson Chi-Square, Shapiro-Wilk, Anderson-Darling, Bartlett, Grubbs, Mann-Kendall Trend, and more.

Reporting
WET Evaluation & Quality Control

WET Evaluation Reports

The CETIS WET Evaluation report assesses a Whole Effluent Toxicity test for compliance with established IWC (Instream Waste Concentration) criteria and test acceptability criteria. CETIS considers the WET test regulatorily significant if the calculated index of toxicity is less than or equal to the permitted IWC.

Data Security

CETIS calculates and stores MD5 hash digests of datasets, providing tamper-proof data integrity verification for regulatory audits and legal proceedings.

Quality Control

Three Types of QC Plots

Levey-Jennings (Shewhart)

Classic control chart for monitoring process stability with warning and action limits.

Cumulative Mean

Track the running average over time to detect gradual shifts in reference toxicant performance.

Two-Sided CUSUM

Cumulative sum plot for sensitive detection of small, persistent trends in your data.

CETIS uses a file-server architecture where the front-end and back-end are separate linked databases. This design supports multi-user environments where licensed copies are distributed across workstations while sharing a single server-based data repository.
