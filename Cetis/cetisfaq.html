General
General Questions

CETIS (Comprehensive Environmental Toxicity Information System) is a professional-level toxicity data analysis and database application developed by Tidepool Scientific, LLC. It is a Microsoft Access-based application designed to thoroughly analyze, maintain, and organize complex and heterogeneous toxicity data from environmental toxicity testing.

ToxCalc was Tidepool Scientific's original product, released in 1992, with over 500 registered users worldwide. CETIS is the next-generation successor that builds on ToxCalc's statistical foundation while adding a powerful database architecture, automated decision-tree logic, quality control plots, WET evaluation reports, and many more advanced features.

CETIS has over 100 registered users spanning commercial environmental laboratories, government regulatory agencies (including the U.S. EPA and U.S. Geological Survey), public and private universities, research institutions, and environmental consulting firms. Users include organizations like CH2M-Hill, Pacific EcoRisk, Texas A&M University, and many more.

CETIS supports freshwater, estuarine, marine, and terrestrial toxicity tests performed on various environmental media including effluents, ambient water, reference toxicants, and sediment samples. It can also be adapted to toxicity tests performed on soils, aerosols, and other media types.

Analysis
Analysis & Statistics

CETIS provides a full suite of methods for both hypothesis testing (NOEL/LOEL) and point estimation (EC/LC/IC values). This includes 4 linear regression (MLE) models, 41 non-linear regression models, Spearman-Karber and Trimmed Spearman-Karber methods, the U.S. EPA TST method, and comprehensive residual analysis diagnostics including Shapiro-Wilk, Anderson-Darling, Bartlett, Grubbs, and Mann-Kendall tests.

CETIS implements decision-making logic that automatically selects the correct statistical method and verifies all assumptions are met. Since different federal and state programs have different rules, you can quickly switch decision trees to match the governing jurisdiction — whether U.S. EPA, Environment Canada, or a specific state. You always retain the ability to override any automated decision.

The WET (Whole Effluent Toxicity) Evaluation report assesses a toxicity test for compliance with established IWC (Instream Waste Concentration) criteria and test acceptability criteria. CETIS considers the WET test regulatorily significant if the calculated index of toxicity is less than or equal to the permitted IWC. This automates a critical step in regulatory compliance.

Technical
Technical Details

CETIS requires Microsoft Access (2010, 2013, 2016, 2019, 2021, or Microsoft 365). Both x64 and x86 versions are supported. CETIS uses a split database architecture with a front-end application installed on each workstation and a back-end database on a shared network drive.

Yes. CETIS uses a file-server architecture where the front-end application is installed on each workstation while the back-end database resides on a shared server. Licensed copies can be distributed among multiple workstations, all accessing the same shared data repository simultaneously.

CETIS calculates and stores MD5 hash digests for each dataset, providing a tamper-proof verification mechanism. This ensures data integrity for regulatory audits, legal proceedings, and quality assurance purposes. Any modification to the underlying data would be immediately detectable.

CETIS Enterprise is a new version currently in development that will support hundreds of simultaneous users, millions of records, and remote access. It will use various versions of SQL Server and Azure SQL, implementing mission-critical database management for large-scale toxicity data operations.
